
# 🚀 Simulador de cohete

Simulador educativo interactivo para visualizar de forma aproximada el lanzamiento de un cohete y experimentar con diferentes características de su diseño.

## 🌐 Ver simulador

👉 **[Abrir el simulador aquí](https://TU-USUARIO.github.io/simulador-cohete/)**

*Importante: sustituye `TU-USUARIO` por tu nombre de usuario de GitHub.*

## ⚙️ Características

- Modificar el diámetro del cuerpo del cohete.
- Ajustar la altura del cuerpo.
- Añadir o quitar la ojiva (punta).
- Cambiar el impulso simulado.
- Visualizar la altura, el tiempo y la velocidad.
- Consultar la altura máxima estimada.
- Observar una gráfica de altura durante el vuelo.

## 🛠️ Tecnologías utilizadas

- HTML
- CSS
- JavaScript

## 📚 Objetivo

Explorar conceptos básicos de física mediante una simulación interactiva y comparar cómo cambian los resultados al modificar los parámetros del modelo.

## ⚠️ Aviso

Este simulador utiliza un modelo físico simplificado con parámetros ficticios. Sus resultados son únicamente educativos y no sirven para predecir con precisión lanzamientos reales.
